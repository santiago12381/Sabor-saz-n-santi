# Sabor & Sazón

Aplicación de escritorio desarrollada en Python para la gestión básica de clientes de un restaurante y el cálculo del costo total del servicio según el tipo de menú y el número de sesiones gastronómicas tomadas.

## Descripción

El proyecto permite registrar la información básica de los clientes y calcular automáticamente el valor total a pagar de acuerdo con el menú seleccionado y la cantidad de sesiones.

La aplicación cuenta con una interfaz gráfica desarrollada con Tkinter y utiliza programación orientada a objetos mediante la clase `GestionClientes`.

## Funcionalidades

- Acceso mediante contraseña.
- Registro de datos básicos del cliente.
- Selección del género.
- Selección del tipo de menú.
- Registro del número de sesiones.
- Asignación automática del costo por sesión.
- Cálculo automático del costo total.
- Generación de reporte de pago.
- Confirmación antes de salir de la aplicación.
